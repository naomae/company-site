# スカイライン・テクノロジーズ 企業サイト

Webアプリ・モバイルアプリ・クラウド基盤の開発を手がける架空のソフトウェア開発会社「スカイライン・テクノロジーズ（Skyline Technologies Inc.）」のコーポレートサイトです。

> ※本サイトは架空の企業のサンプルサイトです。

## 概要

`index.html` 1ファイルで構成された1ページ完結型のサイトです。HTML・CSS・JavaScript をすべて同じファイルに書いているため、ビルドやサーバーは不要です。

### ページ構成

| セクション | 内容 |
| --- | --- |
| ヘッダー / お知らせ | ナビゲーションメニューと、自動で切り替わるお知らせバー |
| ヒーロー | キャッチコピーと主要ページへの導線 |
| 私たちについて | 企業理念と実績の数値 |
| 事業内容 | Webアプリ開発、モバイルアプリ開発、クラウド・インフラ構築、AI・データ活用支援、UI/UXデザイン、保守・運用サポート |
| 導入事例 | 3件の開発事例 |
| 開発の流れ | 相談から運用までの進め方 |
| 会社概要 | 会社の基本情報 |
| 採用情報 | 採用メッセージ |
| お問い合わせ | 入力チェック付きのフォーム（デモのため実際には送信されません） |

### 主な機能

- スマートフォンに対応したレスポンシブレイアウト（ハンバーガーメニュー付き）
- OS の設定に合わせたライトモード / ダークモードの切り替え
- スクロールに合わせたフェードイン表示と、実績数値のカウントアップ
- お問い合わせフォームの必須項目チェック

## ブラウザで index.html を開く手順

### 方法1: ファイルを直接開く

1. エクスプローラーでこのフォルダ（`company-site`）を開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

別のブラウザで開きたいときは、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、開いているブラウザのウィンドウにファイルをドラッグ＆ドロップします。

### 方法2: コマンドで開く

PowerShell でこのフォルダに移動してから、次のコマンドを実行します。

```powershell
Start-Process index.html
```

### 方法3: ローカルサーバーで開く（任意）

`http://` の URL で確認したいときは、簡易サーバーを起動します。Python が入っている場合は次のとおりです。

```powershell
python -m http.server 8000
```

起動したら、ブラウザで <http://localhost:8000/> を開きます。停止するときは `Ctrl + C` を押します。

### 補足

- フォント（Noto Sans JP / Inter）は Google Fonts から読み込みます。オフラインでもページは表示されますが、フォントは端末にある別のフォントに置き換わります。
